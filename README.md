#  PyCrypt

> ابزاری ساده و کاربردی برای رمزنگاری اطلاعات و حفاظت از داده های شخصی شما

---

## ✨ قابلیت‌های کلیدی 
*  **رمزنگاری طبق دلخواه شما**امکان رمزنگاری هم با کلید هم با پسورد 
*  **قویترین الگوریتم دنیا**استفاده از الگوریتم AES-GCM-256 
*  **امکان رمزنگاری با یا بدون فایل موقت**برای راحتی و امنیت فایل های شما
*  **رابط کاربری زیبا** استفاده از اخرین و قویترین فریمورک رابط کاربری PtQt6
